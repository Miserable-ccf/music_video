字库文件路径、固定下载版本（可取得时）、字节数与 SHA-256 见 `catalog.json`。

维护字库时，直接把已取得明确开放授权的原始字体及许可保存到本目录，再登记目录项及校验值。请勿把仅限个人使用、禁止再分发或付费字体加入目录。运行 `python3 tools/check_fonts.py` 核验完整性。

所选字库缺字时，渲染器在测量、换行与绘制时均使用相同的霞鹜文楷繁体备用字形。保留原文字，不进行简繁转换。网页预览会列出发生补齐的文字。

辰宇落雁 2.0 的兼容版本仅移除无效 TrueType hinting 并按保留名称规则改名为 `MoShengHandwriting2`，字形轮廓未修改；原始字体、许可证和 `COMPATIBILITY.txt` 一并保留。
